配置页逻辑总结（2026-08-31 整理，供决策）

一、WebDAV（webdav_page.dart）
- 字段：服务器地址 / 远程目录 / 用户名 / 密码
- 输入即存：无（手动保存）
- 布局：左「连接」OutlinedButton + 右「保存」FilledButton(主题色)
- 保存 _save：四字段全空 → toast「配置为空」并中止；否则 saveWebDavConfig + toast「配置已保存」
- 连接 _connect：校验“服务器地址非空”→ 切到云视图并拉取备份列表

二、语音识别 ASR（ai_record_page.dart）
- 字段：SecretId / SecretKey
- 输入即存：无
- 布局：左「测试」OutlinedButton + 右「保存」FilledButton(主题色)
- 保存 _saveAsr：两字段全空 → toast「配置为空」并中止；否则 saveAsrConfig + toast「保存成功」
- 测试 _testAsr：校验“SecretId 与 SecretKey 非空”→ testAsr → toast 连通/失败

三、AI 新增/编辑（ai_config_detail_page.dart）
- 字段：AI 名称 / Base URL / API Key / 文本模型 / 视觉模型 / 语音模型
- 输入即存：无
- 布局：左「测试」OutlinedButton + 右「保存」FilledButton(主题色)
- 保存 _save：六字段全空 → toast「配置为空」并中止；否则写入配置列表并返回
- 测试 _test：校验“名称 + Base URL + API Key + 文本模型 非空”（逐项提示）→ testAiConnection

四、Supabase 同步（supabase_sync_page.dart）【特殊】
- 字段：昵称 / Project URL / anon public key
- 输入即存：有（昵称、URL/key 改动即写本地，persistIfChanged 去重）
- 布局：左「连接」OutlinedButton + 右「保存」FilledButton(主题色)
- 保存 _saveConfig：先校验“昵称非空”（toast「请先填写昵称」）→ saveCloudConfig + toast「配置已保存」
- 连接 _connect：校验“URL 与 key 非空”→ reconfigure

不一致的点：
1. 前三页保存都只做 allEmpty「配置为空」轻拦截；supabase 保存却在查昵称（保存里带校验）
2. supabase 输入即存与「保存」按钮并存，按钮语义重叠
3. 连接/测试的校验强度不一：webdav 只查服务器；语音查两字段；AI 查四项；supabase 连接查两项、保存查昵称
